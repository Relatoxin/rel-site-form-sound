# FORM/SOUND

[![Русский](assets/readme/ru.svg)](README.ru.md)

A learning concept for a music festival website.

## What works

- Responsive layout and mobile menu.
- Two-day programme with mouse and keyboard navigation.
- CSS animation with reduced motion support.

## Local preview

Open `index.html` for English or `ru.html` for Russian.

## Fonts

Space Grotesk, Overpass Mono, Manrope, JetBrains Mono.
