# Локальные шрифты FORM/SOUND

В `fonts.css` подключены WOFF2-файлы из Google Fonts. Выбраны доступные латинские и кириллические подмножества; пути локальные, `font-display: swap` сохранён.

| Шрифт | Назначение | Источник и лицензия |
| --- | --- | --- |
| Space Grotesk | Название фестиваля и артистов; веса 400–700, рекомендация Riso | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), [OFL](OFL-spacegrotesk.txt) |
| Overpass Mono | Латинские подписи и номера; вес 400, рекомендация Riso | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/overpassmono), [OFL](OFL-overpassmono.txt) |
| Manrope | Русские заголовки и основной текст; веса 400–800 | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), [OFL](OFL-manrope.txt) |
| JetBrains Mono | Кириллические моноширинные подписи; вес 400 | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono), [OFL](OFL-jetbrainsmono.txt) |

Manrope и JetBrains Mono — адаптация рекомендаций для русскоязычной афиши. Вместе с сайтом публиковать `fonts.css`, все WOFF2 и тексты лицензий. Установка шрифтов в систему не требуется.
